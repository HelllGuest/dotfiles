# Explain

Explain the specified code or recent changes clearly and concisely.

## Workflow

1. Focus strictly on the target code or the diff from the last change. Do not narrate unrelated code.
2. Highlight key logic, data flows, edge cases, and design choices.
3. Keep the explanation direct, technical, and formatted for rapid reading.
