# Optimize

Improve performance, memory utilization, readability, or maintainability of the target code without altering its functional behavior.

## Workflow

1. Identify bottlenecks, redundant computations, unnecessary memory allocations, or inefficient data structures.
2. Ensure test coverage exists for the target code before making changes.
3. Apply targeted optimizations while strictly preserving behavior and API contracts.
4. Run verification and affected tests to ensure no regressions were introduced.
5. Report the optimization results with measurable or structured improvements.
