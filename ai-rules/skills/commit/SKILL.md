# Commit

Write a concise Conventional Commit message: `type(scope): summary`
(e.g. `fix(api): handle empty JWT token`). Body only if a reviewer would not
get the why from the diff — keep it short.

## Hard rules
- **Never** include `Co-authored-by`, `Generated by <tool>`,
  "🤖 Generated with...", or any AI-attribution trailer. Strip if it appears.
- **Never** run `git commit`, `git push`, or open a PR unless the user
  explicitly told you to for this action — produce the message only.
- **Never** amend or rewrite history unless explicitly asked.
