# Debug

Root cause analysis and systematic debugging workflow.

## Workflow

1. Reproduce the error or observe the failure pattern (error stack, unexpected state, failing test).
2. Trace data flow and isolate the precise point of failure.
3. Formulate a minimal fix that addresses the root cause without collateral changes.
4. Verify the fix by running affected tests and checking edge cases.
